# 子账号

中控上的账号分为**管理员（admin）**和**子账号（member）**。已有账号都是管理员；在管理员创建子账号之前，一切行为与没有这个功能时相同。管理入口：面板「设置 → 子账号」（仅管理员）。

## 授权单位是服务器

- 管理员把若干台工作机分配给子账号。子账号只能看到和操作这些服务器，以及运行在这些服务器上的项目和服务；即使项目可见，放在未分配服务器上的服务也会被隐藏。
- 中控页、其他服务器、面板设置、加入令牌、Agent 升级、Zeabur / Docker 接管等全局功能，子账号都看不到。
- 一台服务器可以分配给多个子账号，它们共享这台服务器上的项目。管理员不宜把自己的项目放在已分配出去的服务器上。
- 权限每次请求都从数据库重新读取，管理员的修改立即生效；停用、重置密码或删除子账号会让它的会话和 API 令牌全部失效。

## 权限

子账号总是有 `read`，另外可以勾选 `deploy`（默认）、`exec`、`domains`、`delete`、`restore`、`migrate`。`servers`、`settings`、`tokens` 永远不能给子账号。管理员新建子账号或重置它的密码后，面板会提示子账号先改一个自己的密码。

## 配额

可以给子账号设置 CPU（核）、内存（MB）和服务数量上限。设置了配额后：子账号新建服务时如果没写限制，会默认 1 核 / 512 MB；超过配额的创建、调高限制和迁移会被拒绝；降低、停止、删除和迁出总是允许。管理员不受配额限制。

## 根域名

管理员可以为子账号指定可用的根域名。子账号只能在这些根域名下绑定**严格子域名**（不能绑根域名本身，不能用通配符）；不在任何已配置根域名下的主机名视为子账号自己的域名，照常绑定（解析到服务器之前保持 pending）。

## 子账号能用的其他功能

- **API 令牌**：在「设置 → 账号与安全 → API 令牌」管理自己的令牌。令牌最多拥有子账号自己的权限，且每次请求都会与子账号当前的权限和服务器再取交集；CLI 与 `atoll mcp` 用这种令牌时只注册允许的工具。
- **备份**：只能看到和恢复自己项目、自己服务器上的服务备份；恢复需要 `restore` 权限，跨机恢复的目标必须是自己的服务器。
- **问题与通知**：能看到自己项目和服务器的问题，并配置自己的 Webhook / Telegram 通知渠道（最多 5 个）。
- **审计**：每条审计记录都写明是哪个账号（含角色）做的，审计日志本身只有管理员能看。

接口细节见 [API 文档 → Sub-accounts](api.md#sub-accounts-members)。
