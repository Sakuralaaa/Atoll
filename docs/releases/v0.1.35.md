# Atoll v0.1.35

## 新功能

- **一键应用模板**：「创建项目」弹窗新增「应用模板」页签，共 15 个应用：Halo、Ghost、WordPress、PaperGrid、Memos、AList、Vaultwarden、FreshRSS、IT Tools、Gitea、n8n、Uptime Kuma 等。需要数据库的应用会自动带上 PostgreSQL 或 MySQL，随机密钥自动生成，绑定域名时自动填入站点地址。
  - API：`GET /api/v1/app-templates`、`POST /api/v1/app-templates/{id}`
  - CLI：`atoll apps`
- **PaperGrid 博客模板**：基于 [Sakuralaaa/blog](https://github.com/Sakuralaaa/blog)，Atoll 风格界面，SQLite 单容器，内置 MCP 端点（`/api/mcp`），Claude Code、Codex 等 Agent 可直接写文章。需要绑定域名。管理员邮箱 `admin@example.com`，初始密码见服务的环境变量 `ADMIN_INIT_PASSWORD`。
- **英文界面**：侧栏底部可切换中文和英文，`?lang=en` 可强制英文。新增 `README.en.md`。

## 升级

只需升级中控，无数据库迁移。节点不用动。

## 注意

- 模板部署后请登录各应用，修改默认账号和密码。
- 部分模板尚未在真机验证：Ghost、Vaultwarden、n8n 的域名绑定，AList 初始密码，Umami 默认账号。如遇问题请提 issue。
