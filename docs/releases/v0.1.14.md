# Atoll v0.1.14

## 新标志

- 新的 `/A` 标志和字标：直线、平切，跟随明暗主题变色。
- 浏览器标签页有了图标，加到手机主屏也有图标（apple-touch-icon、theme-color）。

## 镜像更新

- **固定版本**：镜像写成 `name@sha256:…`（手动固定，或回滚留下的）时显示「已固定版本」，不再提示「有更新」，也不会自动更新。卡片上的按钮改为「改回跟随 latest」，点了才会取消固定并部署最新镜像。
- **显示版本号**：镜像带 `org.opencontainers.image.version` 标签时，更新卡片、服务状态和服务设置里显示版本号（例如 `1.2.5 · 5c43b1b`），不再只显示一长串摘要。每个摘要只查一次。

## 账号与中控

- 「设置 → 账号与安全」可以修改用户名（需要当前密码；开了两步验证还要验证码）。会话和 API 令牌不受影响。新接口 `POST /api/v1/auth/username`。
- 中控可以重命名：中控页标题旁的铅笔图标，或 `PATCH /api/v1/control {"name": "..."}`。留空则显示主机名。
- 中控和某台服务器在同一台机器上时，中控页「主机」里显示「同机节点」。

## 界面

- 页面说明和设置各节的长段小字收进标题旁的 ⓘ，完整说明移到 [docs/ui-guide.md](../ui-guide.md)，供人和 AI agent 阅读。
- 「CLI 与 API」：同一行的卡片等高；命令自动换行，复制按钮不再压住文字。
- 服务器卡片：徽章移到名字下面一行，名字不再被挤成「Dig…」。
- 手机：标签栏改为一行横向滑动；项目设置的表单改为上下排列；异常横幅的说明可以换行。
- 静默时段改用 24 小时制输入。
- 头像改为用户名首字母。
- 禁用状态的按钮改为灰色，不再像淡紫色的可点按钮。
- 删掉服务器详情里没有意义的「成员」一栏。

## 需要注意

- 只改了中控，agent 没有变化，也没有数据库迁移。
- 版本号在下一次镜像检查时读取（默认每 6 小时检查一次，可点「立即检查」）。中控重启后需要重新读取。

## 从 v0.1.13 升级

「中控 → 更新」，或重跑 `install-server.sh --version v0.1.14`。节点不需要升级。
