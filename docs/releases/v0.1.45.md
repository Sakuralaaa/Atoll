# v0.1.45

## 新功能

- **Docker 部署中控**：官方镜像 `ghcr.io/sakuralaaa/atoll-server` 和 compose 文件，首次打开面板有设置向导；文档站上线（<https://sakuralaaa.github.io/Atoll/>）。见 [docs/install-docker.md](../install-docker.md)。
- **Git 来源**：除 GitHub 外支持 GitLab、Gitea 和任意 git 地址，私有仓库可用 SSH 部署密钥，没有 webhook 时可定时轮询；仓库里没有 Dockerfile 也能构建（按项目类型自动识别）。含迁移 0030。

## 主题

- 「Zeabur」主题改名 **潟湖（Lagoon）**，配色从紫色换成青绿。之前选了它的账号和设备会自动切到潟湖。
- Atoll 默认主题去掉顶部的紫色细线。
- 终端主题的黑夜模式改为低亮度的灰绿控制台，去掉荧光绿、发光文字和扫描线。
- 高对比主题：边框从 3px 改为 2px；黑夜模式改为近黑底、灰白字，不再纯黑纯白刺眼，焦点仍为黄色。
- 马卡龙主题收敛为单一粉色点缀，去掉彩色顶线和多色背景光斑，边框改为中性色。
- 图表、状态点、警告文字等颜色全部改为主题变量，每套主题都能控制。
- 侧栏底部「演示模式」等角色文字不再被截断。

## 安全

- `exec` 的审计日志不再保存命令原文（命令里常带口令），只记程序名、参数个数和 SHA-256；迁移 0031 清掉旧记录里的原文。
- Release 的 `SHA256SUMS` 附 Sigstore 无密钥签名 `SHA256SUMS.sigstore.json`，中控镜像按 digest 签名。验证方法见 [docs/security.md](../security.md#校验下载的文件)。
- 仍未解决：所有节点共用一份备份凭据（计划下个版本按节点分仓库）；`github.com/docker/docker` 的两个告警是 dockerd 守护进程侧问题，Atoll 只用客户端库，上游无修复版本。

## 修复

- 进行中的 agent 升级不再返回 `finished_at: 0001-01-01…`；所有可选时间字段未设置时都直接省略。
- 没有 Cloudflare（拿不到 Origin 证书）的节点，不再每次同步入口都打一条 WARN：同一状态只提示一次，没有路由时不提示。

## 真机测试

在 Debian 13 的真实机器上跑通了全流程：中控从 v0.1.43 直接升级、旧版 agent 一键升级、S3 备份、原地恢复（校验和一致）、项目跨机迁移（PostgreSQL 数据和卷内容一致、源机清理）、Docker 容器接管（演练 → 切换 → 回滚）。

## 升级

先备份中控（含迁移 0030、0031），升级中控，再在「服务器」页点「全部升级」升级 agent。中控与 agent 可以按任意顺序升级（支持从 v0.1.40 起）。
