# v0.1.41（草稿，未发布）

## 子账号（第一阶段）

- 管理员可以在「设置 → 子账号」中创建子账号，给它分配若干台工作机，并选择权限：部署、终端、域名、删除、恢复、迁移。查看权限始终开启。服务器、设置、令牌三类权限只属于管理员。
- 子账号只能看到分配给它的服务器，以及这些服务器上的项目和服务。列表、服务器页和实时事件都会过滤；中控、审批、迁移接管、设置、令牌、加入服务器对它不可见。
- 新建子账号或重置密码后，该子账号必须先修改密码才能使用面板。停用、重置密码或删除子账号时，它的会话和令牌会立即失效。
- 详细说明见 docs/api.md「Sub-accounts」和 notes/subaccounts.md。

## 升级

- 含迁移 0024（只新增表和字段，已有账号自动成为管理员）。升级中控前先备份数据库。迁移不可逆，降级需用备份恢复。
- 只需升级中控，节点不用升级。
- 不创建子账号时，面板的使用方式与之前完全一致。

## 已知限制

- 子账号的服务目前仍能通过内网 mesh 访问其他服务器上的服务。mesh 隔离在第二阶段实现，届时需要升级所有节点。
- 子账号暂时不能创建自己的 API 令牌，也不能使用一键应用模板和根域名列表。
- 子账号缺少权限时，项目页和服务页上的对应按钮仍会显示，点击后提示没有权限。
