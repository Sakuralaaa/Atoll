# Atoll v0.1.20

服务可以设一个「显示名称」，只改面板里看到的名字。

- 服务设置 → 基本 → 显示名称：侧栏、服务页标题、Ctrl K 搜索、域名列表、日志页都显示它；服务页标题旁仍小字显示真实的服务名称（内网主机名）。
- 只改显示名称不会重新部署，也不影响其他服务通过主机名连接它。留空则显示服务名称。
- 改「服务名称」会改内网主机名，设置里补充了提示：其他服务里引用旧地址的变量要一起改。
- 导入时服务名必须被改写的（例如含大写或特殊字符），原名自动保留为显示名称。
- API：Service 新增 `display_name`（≤64 字符）。

## 需要注意

- 只改了中控，agent 没有变化。新迁移 0017（`services.display_name`），升级时自动执行。

## 升级

「中控 → 更新」，或重跑 `install-server.sh --version v0.1.20`。节点不需要升级。
