# Atoll v0.1.36

## 修复

- **节点反复断线（agent disconnected）**：中控推送跨服务器网络配置（mesh）时，会一直持锁等节点回复，最长 40 秒。节点重连时要先拿这把锁才开始读消息，因此读不到心跳就被断开，断开后又重连，又触发推送，形成循环。新建项目、新建服务和应用模板都会触发这个问题。现在锁只用于计算配置，推送放在锁外并行执行，节点连接不再等它。
- PaperGrid 模板的镜像（`ghcr.io/sakuralaaa/blog`）已修复 `/data` 归 root 时无法写入的问题，重新部署即可。

## 升级

只需升级中控，无数据库迁移，节点不用动。
