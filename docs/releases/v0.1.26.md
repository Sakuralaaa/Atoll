# v0.1.26

修复 v0.1.24 多根域名的两个问题。

- **灰云域名证书错误**：根域名证书设为「自动 / Origin CA」后，其下关闭 Cloudflare 代理（灰云、仅 DNS）的域名也会拿到 Origin CA 证书，浏览器直连时报 `NET::ERR_CERT_AUTHORITY_INVALID`。现在灰云域名一律改用 ACME（Let's Encrypt）证书，橙云域名继续用 Origin CA。需要节点能从公网访问 80/443。
- **默认根域名显示「未找到 Cloudflare Zone」**：从旧的单域名设置升级而来的根域名，列表里不再误报（DNS 一直正常）。签 Origin 证书返回 401 / 1016 时也会提示给 token 加「SSL and Certificates: Edit」。

## 升级

中控和所有节点都升级到 v0.1.26（灰云修复在节点的 Caddy 配置里）。v0.1.25 上临时把根域名改回「跟随全局 HTTPS 设置」的，升级后可以再改成「自动」。
