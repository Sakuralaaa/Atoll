# v0.1.33

返回按钮回到你来的地方，删除确认可以双击填入。只需升级中控，节点不用动。

## 修正

- **项目页的返回**：以前项目详情左上角的返回永远回到「我的项目」。现在回到打开这个项目之前的页面：从「我的项目」里点某台服务器卡片、再点项目进入，返回会回到那台服务器的项目列表（按钮上显示服务器名）；从服务器详情、域名页等进入时同理。在项目内部切换服务不会改变返回目标。
- **服务器详情的返回**同样回到来源页（如从项目页进入则回到项目），按钮上显示目标名称。
- **Docker 接管页的返回**：从服务器详情进入时回到该服务器，不再固定回「迁移」。
- **删除后跳转**：删除项目后回到来源页（不再固定回「我的项目」）；删除服务器后回到来源页（来源就是该服务器时回服务器列表）。
- **回到列表时保留滚动位置**：通过返回按钮或浏览器后退回到项目列表、服务器详情等页面，会恢复离开时的滚动位置。
- **删除确认双击填入**：删除项目、服务、服务器等需要输入名称确认的弹窗，双击名称或输入框即可自动填入，仍需手动点「确认删除」。
- 返回目标按浏览器标签页记住（sessionStorage），直接打开链接时仍回到默认页面。
