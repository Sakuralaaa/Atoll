# Atoll v0.1.15

v0.1.14 界面整理的收尾，只改了面板前端。

- 设置页的保存按钮统一：每一节右下角一个「保存」，大小、图标一致。面板、域名与 HTTPS 三节仍共用一个「保存」，有改动时固定在底部并提示「有未保存的修改」。
- 设置项下面和标题 ⓘ 重复的小字删掉了（例如「只写：保存后不再显示」，「已保存」标记和输入框占位文字已经说明这一点）。
- 手机上通知渠道的 Webhook 地址和 chat ID 单独占一行，完整显示，不再被截断。

## 需要注意

- 只改了中控（面板前端），agent 没有变化，也没有数据库迁移。

## 从 v0.1.13 或更早版本升级

「中控 → 更新」，或重跑 `install-server.sh --version v0.1.15`。节点不需要升级。v0.1.14 的变化见 [v0.1.14.md](v0.1.14.md)。
