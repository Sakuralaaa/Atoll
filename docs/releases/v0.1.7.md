## 部署更可靠

- **新版本健康后才删旧容器。** 新容器健康检查不通过、反复重启时，自动换回旧容器和旧配置，部署记录里附上新容器最后 20 行日志。以前旧容器在新容器起来之前就被删掉了。
- **等部署完成。** `GET /services/{id}/deployments/{dep}?wait=60s` 会一直等到部署成功或失败再返回。CLI 加全局 `--wait-ready`（`--ready-timeout` 默认 15m），作用于 deploy、redeploy、rollback、start、restart、env set/unset：失败时退出码 4，并打印原因和构建日志末尾。MCP 新增 `wait_deployment` 工具。面板服务页顶部显示部署进度。

## 安装更安全

- 中控直接提供安装脚本：`GET /install-agent.sh`、`GET /install-server.sh`。面板生成的添加节点命令固定到当前版本，并始终校验 agent 二进制的 SHA-256（新接口 `GET /api/v1/servers/agent-install-command`）。`install-agent.sh` 新增 `--version`。
- 未知的 `/api/`、`/agent/` 路径和文件路径返回 JSON 404，不再返回面板首页。

## 面板

- **Ctrl K / ⌘ K 命令面板**：搜索项目、服务、服务器、域名和页面，直接打开日志或重启服务。侧栏搜索框也能打开。
- 确认弹窗统一：删除服务、项目、服务器、域名、卷仍需输入名称；回滚、轮换 Webhook 密钥改为普通确认；停止、重新启动新增确认。删除环境变量改为 6 秒内可撤销。
- 点头像改为打开账户菜单（账户与安全、设置、退出登录），不再一点就退出。
- 去掉点了没反应的控件：卡片「⋯」、团队切换箭头、项目「通知」入口、「即将推出」的服务类型、只有一个标签的标签栏。

## 修复

- 中控关闭时等待 agent 连接收尾，不再在存储关闭后写入节点状态（CI 偶发失败的原因）。

## 从 v0.1.6 升级

1. **中控**：先在「中控 → 备份」做一次备份，然后「中控 → 更新」，或重跑 `install-server.sh --version v0.1.7`。
2. **节点**：「服务器」页顶部「全部升级」。

没有数据库迁移，可以直接回退到 v0.1.6。
