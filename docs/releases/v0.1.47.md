# v0.1.47

服务页「镜像来源」可直接跳到 GitHub 仓库。只需升级中控。

## 面板

- 来自 `ghcr.io` 的镜像，镜像名可点击，打开对应的 GitHub 仓库（`ghcr.io/owner/repo[/子路径]:tag` → `github.com/owner/repo`），图标换成 GitHub。
- 源码构建（Git 来源）的仓库路径可点击，打开仓库页面。
- 其他 registry（Docker Hub、quay.io、私有仓库等）保持纯文本。
- 链接假设 GHCR 包名与仓库名一致；包名不同的镜像会跳到不存在的页面。

## 升级

只需升级中控，无迁移、无接口变化。agent 不用升级。
