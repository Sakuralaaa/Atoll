# Atoll v0.1.37

## 新功能

- **新增一键应用**：CLIProxyAPI + CPA Manager Plus、grok2api、FlareSolverr、DEEIX Chat、OutlookEmail，应用模板共 20 个。
- **模板输入项和配置文件**：应用模板可以带配置文件（`configs`，只读挂载到容器），以及创建时填写的输入项（如管理员密码，留空自动生成）。
  - API：`POST /api/v1/app-templates/{id}` 的 `inputs`
  - CLI：`atoll apps create APP --set KEY=VALUE`
- **文件页可编辑保存**：服务「文件」页可以直接修改并保存文件（最大 1 MB，大文件分块写入），也能新建文件。Atoll 挂载的配置文件会单独列出，保存时更新服务配置并**重新部署**。从「卷」列表点进来会直接打开该目录。
- **新的部署表单**：「部署服务」改成可折叠分区，镜像以外默认收起：
  - 私有镜像凭据（用户名 + 密码 / Token，加密保存，不再显示；API 新增 `registry_auth`）
  - 环境变量（表格，可标为私有值；也可切到原始 `KEY=VALUE` 文本编辑）
  - 多个端口（HTTP / TCP / UDP）、卷（名称 + 挂载路径）、启动命令、配置文件
- **应用模板选域名**：域名改为「前缀 + 根域名下拉」（默认根域名），实时预览完整地址；留空则不绑定，填 `@` 使用根域名本身。和服务绑定域名用同一个组件。

## 升级

升级中控和所有节点。无数据库迁移。

## 注意

- 新增的几个应用镜像尚未在真机跑过，如遇问题请提 issue。
- 模板部署后请登录各应用，修改默认账号和密码。
