# Atoll v0.1.22

IP 地址默认隐藏，服务器卡片排版修正。

- 面板里的服务器公网 IP、内网（tailnet）IP、登录会话 IP 默认显示为 `203.0.•.•`（IPv6 保留前两段）。地址旁的眼睛可单独查看完整地址；「服务器」页右上角的眼睛按钮一键全部显示或隐藏。
- 「设置 → 隐私 → 隐藏 IP 地址」也能切换。这个开关只存在当前浏览器里，适合截图或共享屏幕；Ctrl K 搜索仍按完整地址匹配。
- 域名、环境变量不受影响（私有环境变量本来就默认隐藏）。
- 服务器卡片：「需要处理」「可升级」等标签移到标题行右侧，不再多占一行；底栏固定在卡片底部，同一行卡片高度一致。

## 需要注意

- 只改了面板前端，没有数据库迁移，agent 没有变化。

## 升级

「中控 → 更新」，或重跑 `install-server.sh --version v0.1.22`。节点不需要升级。
