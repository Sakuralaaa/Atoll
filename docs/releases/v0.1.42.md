# v0.1.42

子账号第二阶段，连同第一阶段收尾一起发布。

## 子账号（第一阶段收尾）

- 子账号可以使用一键应用模板，但只能部署到分配给自己的服务器上（其他服务器返回 400）。如果请求里同时绑定域名，需要子账号有「域名」权限，否则返回 403，可以先留空，之后再绑定。
- `GET /root-domains` 对子账号开放，只返回根域名名称和是否默认，不包含 Zone、证书状态或错误信息。添加、修改、删除根域名仍然只有管理员能做。
- 修复：以前通过应用模板创建项目时，子账号会话可以绕过「域名」权限直接绑定域名。
- 面板会隐藏子账号没有权限的按钮：重新部署、重启、启停、回滚、环境变量增删改、新增服务、创建项目、镜像更新、源码构建设置、端口、卷、备份策略和立即备份需要「部署」权限；快照还原需要「恢复」权限；绑定、解绑域名需要「域名」权限；执行命令和文件入口需要「终端」权限。没有「部署」权限时，服务设置、项目设置和备份策略为只读。
- 子账号看不到中控卡片、添加服务器、Agent 升级、服务器的 SSH 和设置页；打开设置会直接进入「账号与安全」；域名页不再请求面板设置（以前会一直显示加载中）。
- 管理员给子账号分配服务器时，如果这台服务器上已经有项目，会提示该子账号将能看到并操作这些项目。
- 演示模式新增子账号：`?demo=1&member=1`（部署权限）、`?demo=1&member=ro`（只读）、`member=0` 返回管理员视图。

## 子账号（第二阶段）

- **mesh 隔离**：每个项目有自己的 mesh 令牌，由中控根据 master.key 派生，不需要迁移。跨服务器转发器在握手时校验令牌，其他项目的服务连不进来。所有节点都确认支持后，校验才分阶段开启：出口先带上令牌，再是入口，最后强制校验。任何一台节点还是旧版本，或者降级了，校验就自动关闭，新旧节点可以混用。
- **API 令牌**：子账号可以在「账号与安全」里管理自己的 API 令牌。令牌的权限和项目范围不能超过本人，也永远拿不到 servers、settings、tokens 权限，不能用令牌再签令牌。CLI 和 MCP 也受同样限制。账号停用后令牌立即失效。
- **资源配额**（迁移 0026）：管理员可以给子账号设 CPU、内存和服务数上限。新建服务、一键应用、调高资源限制、回滚和迁移时都会检查，超额返回 403。调低、停止、删除和迁出不受限制。升级后已有子账号默认没有配额。
- **备份**：子账号只能看到和恢复自己项目的备份，而且只能恢复到自己的服务器。仓库校验仍然只有管理员能看。
- **问题与告警**：子账号只能看到自己服务器和项目的问题，可以设置自己的 webhook 和 Telegram 通知渠道。webhook 只能发往公网地址。
- **审计日志**（迁移 0025）：每条记录都会写明是哪个账号（管理员或子账号）操作的，可以按 `?user=` 筛选，审计页可以点击账号名只看这个账号的记录。
- **只允许用子域名**（迁移 0027）：管理员在「设置 → 子账号」的编辑框里，为每个子账号勾选「允许的根域」。子账号在这些根域下只能绑定子域名，不能绑定根域本身，也不能用通配符。没有授权的根域都不能用，包括项目默认根域，以及一键应用的域名。不在任何已配置根域下的自有域名照常可用，需要子账号自己添加 A 记录。已被占用的主机名仍然返回 409。管理员不受这些限制。升级后已有子账号默认没有任何允许的根域，已经绑定的域名保留不动。
- `POST /services/{id}/webhook/rotate` 现在需要「部署」权限；没有部署权限的子账号拿不到 webhook 密钥。

## 测试

- 修复两个偶发失败的测试：`TestWebSocketSession`（stop 后的状态帧可能先于结果到达而被丢弃）和 `TestTwoFactorFlow`（固定错误码 "000000" 偶尔恰好是有效验证码）。

## 升级

- 新增迁移 0025、0026、0027，只新增表和字段。升级中控前先备份数据库；迁移不可逆，降级需要用备份恢复。v0.1.40 和 v0.1.41 都可以直接升级。
- 中控和节点谁先升级都可以。mesh 令牌要等所有节点都升级后才会启用；在这之前，跨服务器连接和之前一样。启用过程中，跨服务器连接会短暂重建 2 到 3 次。
- 不创建子账号时，面板的行为和之前一样。

## 已知限制

- mesh 令牌不支持轮换，只能通过更换 master.key 来更换。隔离以项目为单位，同一项目里管理员和子账号的服务仍然互通。mesh 令牌还没有在真实的 tailnet + Docker 环境中验证过。
- 配额只拦截新增和调高，不会限制已有服务的运行。
- 所有节点仍共用同一个 restic 仓库。子账号没有机器 root，只能通过面板操作，靠 API 层隔离。
