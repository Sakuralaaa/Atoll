## 子账号（第一阶段收尾）

- 子账号可以使用一键应用模板，但只能部署到分配给自己的服务器上（其他服务器返回 400）。如果请求里同时绑定域名，需要子账号有「域名」权限，否则返回 403，可以先留空，之后再绑定。
- `GET /root-domains` 对子账号开放，只返回根域名名称和是否默认，不包含 Zone、证书状态或错误信息。添加、修改、删除根域名仍然只有管理员能做。
- 修复：以前通过应用模板创建项目时，子账号会话可以绕过「域名」权限直接绑定域名。
- 面板会隐藏子账号没有权限的按钮：重新部署、重启、启停、回滚、环境变量增删改、新增服务、创建项目、镜像更新、源码构建设置、端口、卷、备份策略和立即备份需要「部署」权限；快照还原需要「恢复」权限；绑定、解绑域名需要「域名」权限；执行命令和文件入口需要「终端」权限。没有「部署」权限时，服务设置、项目设置和备份策略为只读。
- 子账号看不到中控卡片、添加服务器、Agent 升级、服务器的 SSH 和设置页；打开设置会直接进入「账号与安全」；域名页不再请求面板设置（以前会一直显示加载中）。
- 管理员给子账号分配服务器时，如果这台服务器上已经有项目，会提示该子账号将能看到并操作这些项目。
- 演示模式新增子账号：`?demo=1&member=1`（部署权限）、`?demo=1&member=ro`（只读）、`member=0` 返回管理员视图。

## 已知限制

- 子账号的服务仍可通过 mesh 访问其他服务器上的服务，这项隔离在第二阶段完成。子账号暂不能创建自己的 API 令牌。
- `POST /services/{id}/webhook/rotate` 只要求会话，服务端没有对子账号按「部署」权限拦截，面板上已隐藏该按钮。
