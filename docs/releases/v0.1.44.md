# v0.1.44

## 预设主题

- 新增 6 套面板主题：Atoll（默认，原有风格）、极简、Zeabur、终端、马卡龙、高对比，每套都有白天和黑夜。
- 入口：「账号与安全」→「外观」，或用户菜单里的「外观」。点主题卡片即时生效，按账号保存，换设备登录也会跟着切；子账号也能用。
- 地址栏可加 `?style=<主题>` 临时指定主题。旧版中控没有保存接口时，主题只存在本机浏览器。
- 含迁移 0028（`users.ui_theme`），升级中控前先备份。

## 安全修复

- 引用变量（`env/references`）中，普通变量如果展开了 secret（如 `DATABASE_URL=...${PASSWORD}...`），不再返回明文，改为标记 `secret: true`。部署时注入的环境不变。
- 子账号在引用变量里看不到同项目中放在自己无权服务器上的服务。
- 节点令牌只能修改本节点的部署、备份、校验和容器状态记录，令牌泄露不再影响其他服务器。顺带修复迁移后旧节点残留容器把服务标成失败。
- 出站请求防 SSRF（新增 `internal/netguard`，按实际拨号 IP 检查，DNS 重绑定和重定向都会拦）：
  - 子账号 webhook：只能发往公网。
  - 管理员 webhook / Telegram：不能发往回环、链路本地和云元数据地址，私网照常。
  - S3 备份和镜像仓库：只禁云元数据地址，内网 MinIO、私有 registry 照常。`backup_endpoint` 填元数据地址时保存即返回 400。
- 一键更新：最新版是 pre-release 时不自动升级（409 `prerelease`），目标比当前版本旧时拒绝（409 `downgrade_unsupported`）。`install-server.sh --version` 降级需显式加 `--allow-downgrade`。
- `master.key` 权限宽于 0600 时启动自动收紧并告警。

**行为变化**：管理员 webhook 不能再发往本机 `127.0.0.1`（例如同机的 ntfy），请改用私网地址或公网地址。

完整自审报告见 [docs/security-review-2026-11.md](../security-review-2026-11.md)。

## 升级

升级中控（含迁移 0028，先备份），再在「服务器」页点「全部升级」升级 agent（节点令牌作用域修复在中控侧，agent 升级保持版本一致即可）。
