# Atoll v0.1.21

项目也可以设「显示名称」，机器卡片排版修正。

- 项目设置 → 基本 → 显示名称：项目卡片、侧栏、Ctrl K 搜索、服务器详情等处显示它。显示名称可以重复；项目名称仍然全局唯一，CLI 和 API 令牌按项目名称指定项目。
- 改项目名称撞名时返回 409 并给出提示（之前是通用错误）。
- 首页按机器分组的卡片：底栏固定在卡片底部，项目标签多少不同时也对齐。
- API：Project 新增 `display_name`（≤64 字符），POST /projects 也可以带。

## 需要注意

- 只改了中控，agent 没有变化。新迁移 0018（`projects.display_name`），升级时自动执行。

## 升级

「中控 → 更新」，或重跑 `install-server.sh --version v0.1.21`。节点不需要升级。
