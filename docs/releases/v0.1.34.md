# v0.1.34

自定义头像、侧栏导航可拖动排序、几个入口改名。只需升级中控，节点不用动。

**含数据库迁移 `0023_user_ui.sql`（`users` 表新增 `avatar`、`nav_order` 两列），升级中控前请先备份。**

## 新功能

- **上传头像**：设置 → 账号与安全 → 头像。支持 PNG、JPG、WebP，面板会自动居中裁成正方形并压缩到 128×128 后上传，只在面板里显示（侧栏底部）。可随时「恢复默认」回到首字母头像。
  - API：`PUT /api/v1/me/avatar {"avatar": "data:image/webp;base64,…"}`，空字符串清除。仅面板会话可调用；服务端校验类型（PNG/JPEG/WebP，按文件内容识别）和大小（≤ 96 KB）。`GET /api/v1/auth/me` 返回 `avatar`。
- **侧栏导航可拖动排序**：项目、服务器、中控、域名、连接、审批、迁移、设置都可以整行拖动调整顺序（鼠标移动 4px 开始、触屏长按、键盘均可），顺序按账号保存在中控，换设备也一样。
  - API：`PUT /api/v1/me/nav-order {"order": ["servers","projects",…]}`，空列表恢复默认；`GET /api/v1/auth/me` 返回 `nav_order`。没出现在列表里的入口保持默认位置。

- 侧栏顶部 Logo 下的用户名行删除（底栏已有账户信息）。
