# v0.1.29

延迟测量更稳、出错时能看到原因，以及一轮界面修正。

## 延迟

v0.1.28 起服务器卡片显示中控 ↔ Agent 延迟，但有的在线服务器一直是「延迟 —」，看不出原因。这一版：

- **记录失败**：测不到时不再静默丢弃，中控记下连续失败次数、累计失败次数、最后一次的错误和时间。每个连接第一次失败记一条 warn 日志，之后降为 debug，不刷屏。
- **界面显示「超时」**：测量失败时显示红色「超时」，悬停可看到错误（例如 `WebSocket ping: no pong within 20s`）。「—」只在服务器离线或还没测过时出现。
- **pong 不再被饿死**：之前中控的读循环会在同一个 goroutine 里同步处理 Agent 发来的每一帧（状态、监控数据、数据库写入），而 WebSocket 库只有在读的时候才处理 pong，处理慢时 pong 会超过超时时间。现在每个连接有一个按顺序处理帧的工作 goroutine，读循环只负责读。超时从 10 秒放宽到 20 秒。
- **兜底测量**：如果 WebSocket ping 仍然失败（例如路径上的代理吞掉了控制帧），中控改用一条所有版本 Agent 都会立即应答的应用层消息（关闭一个不存在的日志流 `logs.close`）计时，所以**旧版本 Agent 也能显示延迟**。连续 2 次 ping 失败后只用兜底消息，每 8 次重新试一次 ping；悬停提示会注明「改用消息往返测量」。
- `GET /api/v1/servers` 的 `latency` 多了 `method`（`ping` / `message`）、`failures`、`failures_total`、`last_error`、`last_attempt`；没测成功过但已经失败时也会返回（`samples` 为 0）。

## 界面

- **设置**页（含「账号与安全」）内容宽度和其他页面一致，标题不再比其他页面靠右。
- **接管 Docker 容器**页：扫描结果里的警告、需手动处理的原因、容器状态（running → 运行中）、步骤名称和步骤详情、迁移计划的提示都显示中文（英文界面保持原文）。按文案模式翻译，旧版本 Agent 返回的英文同样能翻译；不认识的内容原样显示。Zeabur 迁移页的扫描警告、步骤名称也一样处理。
- **服务器详情 → 管理通道**：「公网 / 内网」标签固定一行显示在上方，长的 tailnet 主机名在下面换行，不再把标签挤到第二行。
- **域名**页顶部：令牌权限改为卡片下方一条独立的标签栏（Zone.DNS 编辑 / SSL 证书编辑，缺失时橙色），缺少权限的后果在下面单独一行说明，不再挤在右上角。
- **按服务器分组**：长服务器名最多换两行（悬停看全名），和「服务器」页的卡片一致；名称区域固定预留两行，卡片仍然等高。
- **服务日志**页：服务名作为页面标题，列名「级别 / 时间 / 内容」和底部「正在实时接收日志」改为中文。
- **从 Zeabur 迁移**页选择服务器时，地区前的国旗改用 SVG（之前是 emoji，在部分系统上显示成方框），「内存 / 硬盘」占用分两行显示，不再在中间断行。
- 标签（Badge）不再继承标题的紧缩字距，「原地接管」等中文标签不再挤在一起。
- 演示模式：一台服务器的延迟是兜底测得的，压力数据（`?demo=1&stress=1`）里的长名字服务器显示「超时」；Docker 接管的步骤详情使用后端原始英文，用来展示翻译。

## 升级

只需升级中控（延迟测量和界面都在中控里），节点不用动。
