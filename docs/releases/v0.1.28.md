# v0.1.28

项目收藏 / 置顶、服务器延迟，以及一轮界面对齐。

## 收藏与置顶

- **置顶**：项目卡片右上角的图钉把项目固定在「我的项目」最上面（按项目和按机器分组两种视图都是）。置顶多个时，用卡片上的 ↑ / ↓ 或把一张置顶卡片拖到另一张上调整顺序。按机器分组时，置顶项目单独一行显示在机器卡片上方。
- **收藏**：项目卡片、列表行和项目页标题旁的星标。筛选标签多了「收藏」（`?filter=fav`），侧栏导航下方列出收藏的项目（最多 8 个，其余点「查看全部」）。
- 收藏和置顶**按账号保存在中控**，换设备、换浏览器都一样。新接口 `GET/PUT /api/v1/me/project-prefs`，新数据库迁移 `0020_project_prefs`（`project_prefs` 表，删除项目或用户时自动清理）。限定项目的 API 令牌只能看到和修改自己范围内的项目。

## 服务器延迟

- 中控每 15 秒通过 Agent 的 WebSocket 连接发一次 ping，记录**往返延迟**的最新值和最近 8 次的平均值。服务器卡片底栏和按机器分组的卡片显示「延迟 38 ms」（< 100 ms 绿色、< 300 ms 黄色、≥ 300 ms 红色，离线或尚未测到显示「—」），服务器详情的运行信息里同时显示平均值。
- `GET /api/v1/servers` 和 `GET /api/v1/servers/{id}` 多了 `latency` 字段（`last_ms`、`avg_ms`、`samples`、`measured_at`）。数值只保存在内存里，Agent 重连后重新计算。
- ping 由 Agent 使用的 WebSocket 库自动应答，**任何版本的 Agent 都能显示延迟**，只需升级中控。

## 界面

- **按服务器分组的卡片高度统一**：项目名标签最多两行，放不下的合并成一个「+N」（悬停可看全部），底栏（项目数 / 运行数）始终贴底；同一网格里所有卡片等高。项目卡片和服务器卡片同样等高（手机单列时不拉伸，避免大片空白）。
- 项目页侧栏的服务筛选标签不再显示数量为 0 的项（当前选中的除外），不再折成三行。
- 中控页「Agent 私网地址」不再在端口号中间断行。
- 新建服务弹窗的搜索框去掉多余的焦点描边。
- 演示模式的压力数据（`?demo=1&stress=1`）加了一台装有 10 个项目的机器，用来检查标签折叠。

## 升级

只需升级中控（面板、API 和延迟测量都在中控里），节点不用动。数据库迁移在启动时自动执行。
