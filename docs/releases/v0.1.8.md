# Atoll v0.1.8

## New
- Problems & notifications: 30s problem watcher, `GET /problems`, `atoll status`, MCP `list_problems`; webhook / Telegram / email channels with quiet hours and recovery notices (`/settings/notifications`).
- Env vars: `PUT /services/{id}/env?redeploy=0`; CLI `atoll env set|unset|import` (`--no-redeploy`, `--replace`, `--secret`, `--exposed`); paste a `.env` in the panel.
- Service page: logs tab, "⋯" menu, log search highlight, level filter, pause/resume.
- Multiple panels: `atoll context ls|current|use|rm`, `atoll login --name`, global `--panel` / `$ATOLL_PANEL`; `atoll completion`.
- MCP tools renamed to `<resource>_<action>`; new `service_stop`, `service_start`, `service_exec`, `env_get`, `domain_list`, `domain_remove`. Old names stay as deprecated aliases (`atoll mcp --legacy-names=false` to hide). Exec now returns `exit_code`.
- `install-agent.sh --uninstall` / `--purge`.

## Reliability
- History retention every 6h (audit 180d, confirmations 90d, finished imports 180d, last 50 failed/superseded deploys per service, expired sessions).
- Agent prunes images unused for 7 days, daily (build cache images kept).
- Service containers default `pids_limit` 4096; Caddy and the agent get lower OOM priority.
- Agent upgrade status persisted (migration 0013), survives control restarts.
