# v0.1.31

新增原生 Android 客户端。中控和节点不用升级，这一版服务端没有改动。

## 新功能：Android 客户端

Release 附件里的 `atoll-android-0.1.31.apk`（Android 8.0 及以上，附 `.sha256`）。源码在 [`android/`](../../android/)，说明见 [android/README.md](../../android/README.md)。

- **面板列表**：保存多个面板（名称、地址、用户名），可添加、编辑、删除；首次打开直接进入「添加面板」。
- **原生登录**：和网页登录页走同一套接口（`POST /api/v1/auth/login`、`POST /api/v1/auth/login/2fa`）。地址自动补 `https://`，先用 `GET /api/v1/auth/status` 确认是 Atoll 面板（http → https 跳转会自动跟随）；开启两步验证的账号接着输入 6 位验证码，也可以改用恢复码。密码错误、无法解析域名、连不上、超时、证书不受信任、失败次数过多、面板未初始化都有中文提示。
- **凭据加密保存**：「记住密码」打开时，密码用 EncryptedSharedPreferences（Android Keystore 密钥）保存在本机，不参与系统备份；可选「打开前验证指纹 / 面容」（也可用锁屏密码）。
- **全屏面板**：登录得到的 `atoll_session` Cookie 原样写入 WebView 后打开面板。支持下拉刷新（只在页面顶部触发，不和页面内滚动冲突）、返回键先回退页面再回到列表、文件上传、下载（带登录 Cookie；页面生成的 `.env`、恢复码、日志等文件保存到「下载」）、其他网站用浏览器 / Custom Tabs 打开、加载进度条、离线 / 出错页带「重试」。状态栏和导航栏颜色跟随面板的深色 / 浅色主题，旋转屏幕不重新加载，进程被系统回收后回到原来的页面。
- **会话过期**：面板跳到登录页（或接口返回 401）时，用保存的密码静默重新登录一次；没有保存密码、需要两步验证或重新登录失败时，回到原生登录页。在网页里主动退出登录会回到面板列表。
- **快速切换**：屏幕左侧中间的小把手打开抽屉，可切换面板、刷新、在浏览器中打开、回到列表或退出登录。
- 启动画面和自适应图标使用 Atoll 标志。

## 升级

服务端无需任何操作。首次安装 APK 时需要允许「安装未知应用」；以后的版本使用同一个签名密钥，可以直接覆盖安装。
