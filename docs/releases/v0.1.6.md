## 新功能：在面板里升级 agent

- 「服务器」页顶部会提示有几台 agent 可以升级，点「全部升级」一次升完（每次 3 台）；单台在服务器详情「设置 → Agent」里升级。CLI：`atoll servers upgrade-agent --all`。
- 过程：节点从中控下载托管的新版 agent，校验 SHA-256 和版本号后替换并重启。新 agent 两分钟内没连回中控就自动换回旧版，结果显示在服务器卡片上。容器一直运行，不会重建。

## 从 v0.1.5 升级

1. **中控**：面板「中控 → 更新」，或重跑 `install-server.sh --version v0.1.6`。
2. **节点**：v0.1.5 及更早的 agent 还不会自己升级，需要在每台节点上重跑一次（已加入的节点不需要 token）：
   ```bash
   curl -fsSL https://raw.githubusercontent.com/Sakuralaaa/Atoll/main/install/install-agent.sh \
     | sudo sh -s -- --server https://panel.example.com
   ```
   之后的版本都能在面板里升级。

从 v0.1.4 升级请先看 [v0.1.5 的说明](v0.1.5.md)。
