# v0.1.50

## 新功能

- **硬件设备映射**：服务「设置」页新增「硬件设备」，可为容器打开 KVM（`/dev/kvm`，安卓模拟器、虚拟机）、TUN（`/dev/net/tun`，VPN）、FUSE（`/dev/fuse`）、GPU（`/dev/dri`，转码）。等同 `docker run --device`，只接受这几个设备，其他一律拒绝。
- **共享内存**：「资源限制」新增「共享内存」（`/dev/shm`，MB），等同 `--shm-size`；留空为 Docker 默认 64 MB。浏览器、安卓模拟器一般要 1024–2048。
- API：`POST /projects/{id}/services`、`PATCH /services/{id}` 新增 `devices`、`shm_size_mb`，回滚会一并恢复，见 [docs/api.md](../api.md)。

## 说明

- 服务器上不存在的设备会让部署失败并写明原因（没有 KVM 时提示该机器不支持 KVM）。
- agent 低于 v0.1.50 时，带设备或共享内存的修改会被拒绝（409 `agent_outdated`），不会静默丢掉设置。
- 新建服务弹窗、CLI、MCP 暂未提供这两项，先创建服务再到设置页打开。
- 没有设置设备的已有服务升级后不会被重建。

## 升级

含迁移 0034，先备份中控，再升级中控；在「服务器」页点「全部升级」升级 agent 后才能使用设备映射。
