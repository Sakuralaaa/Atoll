# Atoll v0.1.39

## 修复

- **CPA 管理面板登录密钥**：CLIProxyAPI 模板里 CPA Manager Plus 的 `CPA_MANAGER_ADMIN_KEY` 之前是随机生成的，用创建时填写的管理密钥登录不了。现在它直接引用 cli-proxy-api 的 `MANAGEMENT_PASSWORD`，两个面板用同一个密钥。

## 升级

只需升级中控。无数据库迁移。

## 注意

- 已部署的 CLIProxyAPI 不会自动变更：把 cpa-manager-plus 的环境变量 `CPA_MANAGER_ADMIN_KEY` 改成 cli-proxy-api 的 `MANAGEMENT_PASSWORD` 的值（或 `${cli-proxy-api.MANAGEMENT_PASSWORD}`），然后重新部署；或从模板重新创建。
