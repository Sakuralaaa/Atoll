# v0.1.49

## 新功能

- **PostgreSQL 大版本一键升级**：镜像更新卡片的「大版本」一行，PostgreSQL 服务可点「一键升级」（例如 17 → 18）。过程：停止服务，用旧版本导出全部数据（含角色），用新版本在新目录导入，核对库和表的数量一致后换入并部署新版本。任何一步失败都会放回旧数据、用旧版本启动；新版本部署失败也会自动回到旧版。
- 旧数据保留在节点上，可随时「回到旧版本」（会丢失升级后写入的数据），确认无误后点「删除旧数据」释放空间。保留旧数据期间不能再次升级。
- 新 API：`GET/POST /api/v1/services/{id}/db-upgrade`、`POST .../db-upgrade/rollback`、`DELETE .../db-upgrade/old`，见 [docs/api.md](../api.md)。

## 说明

- 升级期间服务停机，时长取决于数据量；需要约两倍数据量的空闲磁盘。
- 仅支持从镜像部署、没有主机目录卷的 PostgreSQL 服务。MySQL、MongoDB 暂不支持。
- 磁盘空间不足的报错文案不再提「演练」。

## 升级

含迁移 0033，先备份中控，再升级中控；在「服务器」页点「全部升级」升级 agent 后才会出现「一键升级」。
