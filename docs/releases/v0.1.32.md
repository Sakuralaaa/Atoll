# v0.1.32

侧边栏整理，收藏可以拖动排序，服务拖动换成带动画的新实现。只需升级中控（含迁移 0022），节点不用动。

## 界面

- **侧边栏重新排版**：去掉搜索框和导航之间的分隔线与空白，导航行距统一。侧边栏分三段：上面的 Logo、搜索、导航固定；中间的收藏（项目页里是服务列表）单独滚动，滚动条变细、鼠标移上去才出现，底部淡出；下面的异常提示、「中控在线」和账户固定在底栏，不再压住最后一个收藏。窗口很矮时整个侧边栏滚动。手机抽屉用同一套布局。
- 收藏和服务列表里的小图标阴影改为 2px，收藏标题、计数与列表对齐；服务列表标题显示服务数。

## 拖动排序

- **收藏可拖动排序**：顺序按账号保存，换设备也一样；新收藏排在最后。侧边栏最多显示 30 个收藏，超出时显示「查看全部」。
- **服务拖动重写**（基于 dnd-kit）：整行都能拖（鼠标移动 4px 后开始，单击仍然打开），触屏长按约 0.2 秒开始拖，也支持键盘（Tab 选中后空格拿起、方向键移动）。拖动时这一行抬起、轻微倾斜，原位置留虚线占位，其他行顺滑让位，松手有落位动画。新顺序立即显示，保存失败自动回滚。规则不变：按状态筛选时或只有一个服务时不能拖。

## 接口

- `GET /api/v1/me/project-prefs` 的 `favorites` 按保存的顺序返回；`PUT` 按请求里的顺序保存（重复 id 只算一次）。迁移 `0022_favorite_order.sql` 给 `project_prefs` 加 `fav_order`，已有收藏按原来的顺序（项目 id）编号。

## 升级

先备份中控，再升级中控。节点无需升级。
