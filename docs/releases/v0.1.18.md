# Atoll v0.1.18

只改了 agent：Zeabur 接管迁移 PostgreSQL 时保留表的所有者和授权。

- 导出加 `--create`，恢复改为 `pg_restore --create`（先删 Atoll 这边的副本）：数据库本身的所有者、CONNECT/CREATE 授权和设置一并恢复，之前 `createdb` 建的新库没有这些。
- 不再用 `--no-owner`：v0.1.16 起会先复制角色，表可以归还给原来的角色。应用用非超级用户角色（例如 `workbench_worker`）登录、并拥有自己的表时，之前会报 `permission denied`（42501）。

## 升级

先更新中控（面板一键升级 agent 会升到中控的版本），再在「服务器」页升级做 Zeabur 接管的节点。
