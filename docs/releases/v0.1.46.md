# v0.1.46

面板体验整理：主题、迁移页、设置页、长列表和弹窗。只需升级中控。

## 主题

- **潟湖**和**马卡龙**改用 Atoll 的块状风格：2px 边框、硬偏移阴影、斜体标题，边框和阴影用主题自己的深色而不是纯黑。
- 潟湖白天用清爽的绿色；黑夜改为低眩光的豆沙绿，去掉光晕和网格。
- 马卡龙改为玫红，去掉背景光斑。
- **高对比**的黑夜模式重做：不再有大块浅色（按钮、标签、提示框改为深色底浅色字），边框改为中灰，正文对比度约 12:1，夜里不刺眼；白天不变。
- 移除**终端**主题。已选终端的账号和设备会自动回到 Atoll，可在「设置 → 通用 → 显示」重新选择。

## 迁移页

- 「迁移」先选来源（Zeabur / Docker），下面是迁移记录和 CLI 用法；Zeabur 向导在 `/import?from=zeabur`。
- 两个向导改用细进度条和圆点，服务器列表和迁移记录超过 5 行在框内滚动。
- 去掉页面上的说明小字，说明移到 README 的「迁移与接管」一节。
- 中控页的「迁移中控」改为一步一屏，右上角链接到完整文档。

## 设置

- 设置页顶部分为 **通用 / 账号 / 团队**（团队仅管理员可见），每页按分组切换，一次只显示一组：
  - 通用：常规、域名、通知、备份、网络、服务、显示（主题、服务器归属、隐私）。
  - 账号：资料（头像、登录会话）、登录（用户名、密码、两步验证）；子账号另有配额、通知。
- 分组记在地址的 `#` 里，旧链接（`#backup`、`#network`、`/settings/security#appearance` 等）仍然可用。
- 子账号的「通用」只有「显示」一组。
- 开启两步验证后，修改密码或用户名时在弹窗里输入验证码，不再放在表单里。
- 证书和私钥输入框默认更矮。

## 列表和弹窗

- 长列表在框内滚动，表头不动：审计日志、域名、备份快照、审批历史、登录会话、部署记录（状态页弹窗和日志页）、API 令牌、子账号令牌。
- 弹窗改为屏幕居中（新建服务和 Ctrl K 搜索仍靠上）。

## 升级

只需升级中控，无迁移、无接口变化。agent 不用升级。
