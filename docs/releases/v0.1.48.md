# v0.1.48

## 新功能

- **服务磁盘占用**：agent 每 10 分钟统计每个服务的卷目录和容器可写层（按实际占用的块计算，硬链接只算一次，不跟随符号链接、不跨文件系统）。服务「用量」页新增磁盘曲线（保留 8 天），下方列出各卷和可写层的大小。服务状态页不变。
- **卷容量上限（软限制）**：在服务「硬盘」页给每个卷设上限，可选超出后「停止服务并告警」（默认）或「仅告警」。用到 80% 时出现「卷容量告警」，并改为每分钟统计一次。超限被停止后手动启动或重启，会给 1 小时宽限，方便清理数据。主机目录（host_path）卷不统计、不能设上限。
- 新 API：`GET /api/v1/services/{id}/disk`、`PUT /api/v1/services/{id}/volumes/{name}/limit`，见 [docs/api.md](../api.md)。

## 说明

- 卷是 bind 目录，Docker 的 `--storage-opt size` 对它无效，所以这是软限制：超出后由中控停服务，不是写入时立即拒绝。
- 旧版 agent 不上报磁盘，用量页会提示升级 agent。

## 升级

含迁移 0032，先备份中控，再升级中控；在「服务器」页点「全部升级」升级 agent 后才会有磁盘数据。
