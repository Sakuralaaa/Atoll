# Atoll v0.1.19

面板更好分辨多台机器上的项目，并按 IP 自动显示国旗和服务商。

- 项目页按机器分组：项目分布在两台以上机器时，一台机器一张卡片（服务商图标、IP、项目名、运行数和失败数），点进去只看这台机器的项目，筛选计数也只算这台；在里面新建项目默认放到这台机器。右上角服务器图标可切回平铺，选择会记住。
- 按 IP 显示国旗和服务商（参考 Komari 探针）：中控用 ipinfo.io（备用 ip-api.com）查询每台服务器的公网 IP，记下国家、城市和所属网络（ASN）。区域没填时显示「城市, 国家」和国旗；服务商没填时按所属网络推测图标（例如 AS31898 Oracle → Oracle，AS36352 HostPapa/ColoCrossing → RackNerd，后者是推测）。手动填写的区域和服务商优先。
- 国旗改用 SVG（按需加载，每个约 1 KB），Windows 上不再显示成两个字母。
- 服务商名称不区分大小写，并支持常见简写（rn、do、gcp、bwh……）；新增 VMISS、OVH、Google Cloud、AWS、Azure、阿里云、腾讯云、Akamai/Linode、Scaleway、Contabo、netcup、UpCloud、IONOS、Hostinger、Cloudflare、BandwagonHost、DMIT、GreenCloud 图标。
- 「设置 → 服务器归属」可以关闭 IP 查询（会把服务器 IP 发给上述两个服务）。

## 需要注意

- 只改了中控，agent 没有变化。新迁移 0016（`nodes.geo`），升级时自动执行。
- 查询在中控上进行，每次间隔 2 秒，结果缓存到 IP 变化或满 30 天；内网、Tailscale（100.64/10）和文档用地址不查。中控访问不了外网时只是不显示国旗。

## 升级

「中控 → 更新」，或重跑 `install-server.sh --version v0.1.19`。节点不需要升级。
