# v0.1.27

按界面评审整理域名页和几个列表页。

## 域名

- **每行显示橙云 / 灰云和证书类型**：橙云旁提示「100 秒超时」，灰云旁提示「会暴露源站 IP」；证书显示 Origin CA、ACME 或 HTTP（服务器上没有证书）。灰云却还是 Origin CA 的（跟随全局 Origin CA 证书）标黄，提示改用「自动」或 ACME。
- **点标签切换代理**：配置了 Cloudflare 令牌时，点橙云 / 灰云标签确认后直接改 Cloudflare 记录（新接口 `PATCH /api/v1/domains/{id}` `{"proxied": false}`）。根域名用 Origin CA 时，切成灰云的域名改用 ACME 证书（v0.1.26 的逻辑），DNS 生效后自动签发；切回橙云恢复 Origin CA。切换期间路由不中断。开了「需要面板批准」的 API 令牌会进入待确认（`domain.proxy`）。
- **绑定域名的代理选项改成两张卡片**：「Cloudflare 代理（推荐 · 防护）」和「直连（长请求 / 非 HTTP）」，各写明代价：橙云单个请求 100 秒超时、只代理 HTTP(S)；直连会暴露源站 IP。服务页里的绑定域名弹窗同样。
- **令牌权限检查**：域名页顶部原来固定写「Zone.DNS 编辑」，现在由中控实际探测（新接口 `GET /api/v1/cloudflare/token-check`，缓存 10 分钟）。有根域名用 Origin CA（证书模式「自动」）时还会显示「SSL 证书编辑」（Zone.SSL and Certificates: Edit）是否具备，缺失标黄并说明否则签证书会报 1016。探测用 Cloudflare 必然拒绝的请求（无效内容的 A 记录、没有 CSR 的证书申请），不会创建任何东西。
- 域名列表里项目名和服务名相同（如 `qa-bot / qa-bot`）时只显示一个。
- `GET /domains` 和 `GET /services/{id}/domains` 的每条域名多了 `cert` 字段（`origin` / `acme` / `http`）。

## 其他页面

- **异常提示不再三处重复**：侧栏的「异常」计数保留；页面顶部的红条只显示与本页相关的问题（服务器页只有服务器离线、磁盘，项目页只有服务、部署、备份和域名），可以收起，收起状态按页面记在浏览器里。
- **「我的项目」默认一个项目一张卡**，卡片上显示服务数、状态和域名。按机器分组改为可选（排序按钮旁的服务器图标），`?server=` 仍可只看一台机器。之前的分组偏好不沿用，需要的话再点一次。
- **服务器卡片**：名字完整显示（过长换行），在线状态和系统版本各占一行，「需要处理」和 agent 升级徽章挪到卡片底栏。
- **按钮、徽章、版本号的中文不再显示方块**：等宽字体栈加了中文回退（内置的 Noto Sans SC，再到 PingFang SC、Hiragino Sans GB、Microsoft YaHei、Noto Sans CJK SC、Source Han Sans SC），粗细与正文一致。
- **中控页**：「数据」卡补上数据目录所在硬盘的可用空间和数据库占比，不再留大片空白；备份「位置」的两个徽章改为「本机磁盘」「异地存储桶」，悬停有说明。
- **新建服务**多了「从已有 Docker 容器接管」，直接打开 `/import/docker` 并选好当前项目的服务器（或弹窗里选的服务器）。接管仍会新建一个 Atoll 项目，不会并入当前项目。

## 升级

只需升级中控（面板和 API 都在中控里），节点不用动。灰云域名在 Origin CA 根域名下改用 ACME 依赖节点 v0.1.26 及以上。
